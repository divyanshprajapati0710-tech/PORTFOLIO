# 💼 Divyansh Prajapati – Developer Portfolio

A modern, responsive developer portfolio built with **Next.js**, showcasing my projects, skills, education, and contact information. Designed with a clean UI, smooth animations, and a dark developer-inspired theme.

## 🚀 Features

* Modern and responsive design
* Smooth scrolling and animations
* About Me section
* Education timeline
* Featured Projects
* Skills showcase
* Contact section
* Optimized with Next.js

## 🛠️ Tech Stack

* Next.js
* React.js
* CSS Modules
* JavaScript / TypeScript
* HTML5
* CSS3

## 📥 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the project folder

```bash
cd <project-folder>
```

### 3. Install dependencies

Before running the project, install all required packages:

```bash
npm install
```

> **Note:** This command installs all required dependencies listed in `package.json` and generates the `node_modules` folder and `package-lock.json` (if it isn't already present).

### 4. Start the development server

```bash
npm run dev
```
